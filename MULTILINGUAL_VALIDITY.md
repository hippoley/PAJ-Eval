# Multilingual validity

Probe Player currently exposes ten language choices: English, Simplified Chinese, Traditional Chinese, Japanese, Korean, Spanish, French, German, Portuguese, and Russian.

This is a product capability before it is a research capability. The player shell can be localized immediately; confirmatory cross-language research requires a stricter gate.

For every scenario variant, reviewers should compare languages on: task objective, role clarity, amount of information, uncertainty strength, causal hints, salience of evidence, action affordances, politeness/directness, intervention intensity, and whether technical terms carry different prior knowledge.

Translations should be reviewed by fluent humans with the latent world and intended construct hidden where possible. A back-translation check can catch gross drift but is not sufficient. The stronger test is behavioral: within-language causal twins should move behavior when the latent world changes, while semantically equivalent surface variants should not create large unexplained shifts.

Do not pool multilingual participant data merely because all strings exist. Record locale in every session and report language-stratified results until measurement invariance is supported.
